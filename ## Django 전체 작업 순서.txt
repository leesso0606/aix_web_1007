## Django 전체 작업 순서

1. 프로젝트 폴더 이동 — `cd`
2. 앱 생성 및 등록 — `startapp`, `settings.py`
3. 모델 작성 — `models.py`
4. 데이터베이스 반영 — `makemigrations` → `migrate`
5. 기능 작성 — `views.py`
6. URL 연결 — 앱 `urls.py` → 프로젝트 `urls.py`
7. HTML 작성 — `templates/*.html`
8. 서버 실행 및 테스트 — `python manage.py runserver`

암기 순서: 폴더 → 앱 → 모델 → DB → 뷰 → URL → HTML → 테스트

※ 이미 만들어진 앱이나 모델은 다시 만들 필요 없어요.

## 3. 학생 관리 기능을 만들 때의 순서

1. **학생 입력** — `swrite`
   - 입력 폼 작성 → POST 전달 → DB 저장

2. **학생 목록** — `slist`
   - DB에서 전체 학생 조회 → 목록 출력

3. **학생 상세보기** — `sview`
   - 학생 번호로 조회 → 상세 정보 출력

4. **학생 수정** — `supdate`
   - 기존 정보 조회 → 수정 폼 표시 → 수정 후 `save()`

5. **학생 삭제** — `sdelete`
   - 삭제 요청 → DB에서 삭제 → 목록으로 이동

## 4. 헷갈릴 때 기억할 핵심

- `models.py` : 어떤 데이터를 저장할까?
- `views.py` : 어떤 기능을 처리할까?
- 앱 `urls.py` : 어떤 주소를 어떤 view와 연결할까?
- 프로젝트 `urls.py` : 어떤 앱의 URL을 연결할까?
- `templates/*.html` : 사용자에게 어떤 화면을 보여줄까?
- `settings.py` : 어떤 앱과 설정을 사용할까?

### Django 요청 처리 흐름

사용자(브라우저) → `urls.py` → `views.py` → 필요하면 `models.py`로 DB 처리 → HTML 화면 출력

### 핵심 암기

- **Model** = 데이터
- **View** = 기능
- **URL** = 주소 연결
- **Template** = 화면
